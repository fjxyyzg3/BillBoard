# 账号与数据申请

本流程说明账号重新启用、永久删除和数据恢复申请的处理原则。它不提供公开清库入口，也不构成执行真实删除、覆盖恢复或重新启用的授权；每次实际操作都须单独核实并明确批准。

## 申请与身份核实

用户先查看应用内 `/account/privacy`，通过取得邀请时已建立的私下联系渠道联系维护者，说明本人账号、申请类型、拟处理范围和原因。不要发送密码、邮箱授权码、录音、原账单或邮件验证／恢复链接；不要在仓库、公开 issue、诊断或聊天截图中提交真实账号及财务内容。

维护者使用可核实的既有联系证据与服务端账号记录确认本人；涉及家庭历史时，还须核实原家庭负责人、共同数据的处理权限及其他成员权益。昵称、家庭名称、新提供的邮箱或转发的链接不能单独证明身份或归属。身份、权限或范围无法核实，或共同数据存在争议时，不执行对应操作。

## 处理范围

| 申请 | 核实与边界 |
| --- | --- |
| 重新启用本人账号 | 另行核实本人及启用范围，不通过密码找回恢复停用状态。不恢复旧会话、旧成员身份或旧任务；需要家庭访问时，使用新的有效邀请建立新身份。 |
| 本人资料处理 | 先盘点账号与历史成员被共同账务引用的情况。个人申请不能授权删除其他成员的资料或共同家庭账目；任何保留引用或去标识方案均须另行核验并获明确授权。 |
| 家庭历史永久删除 | 核实原负责人、共同数据处理权限、受影响成员及准确范围，说明历史交易、导入来源和统计将受到的影响，再取得覆盖该范围的明确授权。关闭家庭不等于这项授权。 |
| 从备份恢复数据 | 核实备份来源、目标环境、允许恢复的范围，以及备份后新增账目和已执行的删除／停用／撤销。不得覆盖未授权数据、丢弃新写入或恢复已经确认删除的数据。 |

退出、移除、账号停用和家庭关闭均保留共同历史，不触发永久删除。账号、成员与账本的引用必须整体核对，不能借账号级联删除清空家庭。`ImportDraft`、`ImportDraftRow`、来源指纹、退款关联及映射包含长期账务元数据，不能按临时文件清理；软删除记录也不等于已经永久删除。

OPS 仍只负责其既有账号安全与平台注册邀请操作，不扩展到账号删除、共同账务维护或代登录。维护者的数据库访问能力不代替本人或共同数据范围的授权。

## 备份与保留说明

首版归档资料和私有备份没有自动清理周期，不承诺申请后全部历史副本立即抹除。处理前须盘点已核实的工作库、备份、恢复演练副本和导出产物，说明本次覆盖哪些副本、哪些仍被保留、保留原因及访问限制；未确认的副本不能标为已删除。

删除前的保护性备份也可能包含申请处理的数据，须在本次方案和授权中说明。删除备份或扩大清理范围同样需要对应授权，不能为完成某个账号申请而删除其他家庭的备份。供应商侧已接收的数据须按其实际处理边界另行核实，应用侧清理不代表供应商侧删除。

实际身份材料、目标标识、备份位置、具体命令及核验结果只保存在私有、未跟踪的受控记录中。公开文档只保存原则；最小操作记录使用必要标识、范围、时间、授权依据、计数与摘要，不记录密码、密钥、原文或真实生产入口。

## 实际处理前后

1. **准备可审查方案。** 只围绕已核实的本人或家庭范围，列明目标记录及引用、保留数据、受影响功能、备份限制、预期计数与摘要变化，以及失败后的恢复方式。范围扩大或方案实质变化时重新取得具体授权。
2. **先做隔离演练。** 涉及数据删除或恢复时，按[恢复流程](restore.md)与[家庭账本迁移流程](household-ledgers-migration.md)核验私有备份，在独立、核实为空的 PostgreSQL 17 环境实际恢复并演练方案。真实备份不交给外部 AI，不在正式库运行会清数据的集成测试或 Playwright。
3. **取得本次执行授权。** 将具体目标、影响、保留副本、核验与回退结果交由有权授权者明确批准。申请、停用、关闭、审阅通过或功能验收均不代替真实删除／恢复的逐次执行授权。
4. **停写并保全最新数据。** 在实际执行窗口收敛入口、web、OPS 和其他写入者及在途任务，核对目标归属，取得最终私有备份与摘要并验证可恢复性。只有已演练且获授权的明确范围可执行；不使用 seed、全库清空或旧快照覆盖替代定向处理。
5. **核验后再恢复访问。** 比较预期与实际计数、摘要、历史归属、引用及家庭统计；验证该失效的账号、会话和任务仍失效，未授权范围不变。失败时保持受影响服务停止并保留数据与证据，按已批准的恢复方式处理，不能将部分执行报告为完成。
6. **记录实际结果。** 私下告知已处理范围、仍保留的副本和未完成事项，保留防止后续恢复撤销该处置的最小私有记录。本期功能验收只审阅此流程和使用隔离合成数据验证，不执行真实删除来证明可用。

## 后续恢复的约束

恢复前必须对照私有授权与处置记录，核对备份之后已确认的删除、停用、家庭关闭、密码变更、会话与邀请撤销。隔离恢复演练须保留这些结果；不能因恢复旧备份而重新开放已删除数据、旧密码、旧会话、旧身份或旧任务。无法确认或落实时，恢复库保持隔离，不恢复正式访问。

正式库接受新写入后，回退也必须先停止写入、保全并核验最新数据，不能切回旧快照丢弃新增账目。永久删除造成的统计变化须作为本次明确授权的预期结果记录，不能通过恢复已删除记录来“修平”统计；未授权范围和其他家庭的账务仍须保持一致。
