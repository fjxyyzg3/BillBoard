# 家庭报表分析增强

## 目标

在现有首页提供可追溯的家庭收支分析，使用户能够比较周期变化、定位分类增减、按日期复盘，并查看消费金额分布。全部分析使用现有账本数据，保持移动优先、中文默认及英文切换。

## 决策基线

### 需求边界

- 保留 `/home` 作为入口、整个家庭作为统计范围。包含同比环比、分类变化、消费日历、累计支出比较、分类年度走势、金额分布和自动月度摘要。
- 日期选项包含现有月、年、全部，以及最近三个月、自定义起止日期；图表与明细共享范围，切换应用导航保留主范围。
- 不包含预算、商户排行、商户补全、固定支出统计、固定支出标记、自动记账或额外账户模型。这些功能已由用户明确移除。
- 所有金额以已有交易的 `amountFen`、方向和发生日期为准，保留导入及自然语言录入的退款口径，不回写历史交易。
- 自动摘要使用本地确定性统计规则，展示所选月份的事实及可核对明细；不调用外部 AI、不发送通知、不生成持久化报告副本。
- 金额分布、中位数、最大支出、前五笔占比针对有效支出；分类分析可切换收入与支出。
- 空白只能表述为无已记录数据；没有基期记录时显示不可比较，基期指标为零时只显示金额变化，不制造百分比或“省钱”的结论。

### 技术决策

- 复用现有 Next Server Components、Prisma/PostgreSQL 聚合和记录查询。金额、日期、类别聚合在服务端进行，客户端仅接收展示所需的聚合数据。
- 不改变 Prisma schema、导入格式、登录流程和生产部署拓扑。扩展共享范围模型、分析查询、图表组件及金额条件明细跳转。
- 查询必须由当前 AppSession 派生家庭和成员，并确认成员属于该家庭；所有有效交易查询包含 `deletedAt: null`。
- 日期与比较全部使用 `Asia/Shanghai`。金额条件继续以绑定家庭的加密 token 进入 URL；交易备注、金额明文和其他财务细节不写入 URL、客户端持久化存储或日志。
- 复用已有 UI 风格与依赖；无需新增报表缓存、后台任务、预聚合表或外部服务。
- 本次 wiki 目标为 none；规格保存实施必需的设计和验收，不另建重复知识页面。

## 设计视图

### 功能设计

首页顶部保留日期和收支总览；分析区以清晰的视图切换呈现，避免把全部图表纵向堆叠在手机首页。已有趋势、分类排行及明细能力继续可用。

| 分析 | 展示与交互 |
| --- | --- |
| 周期比较 | 本期与上期、去年同期的收支和账面结余，显示金额增减；有有效基数时显示百分比。 |
| 分类变化 | 按增减金额排序，展示两期金额、笔数、单笔平均金额；点击分类进入该期对应记录。 |
| 消费日历 | 月历显示每日已记录支出和颜色强度；跨月范围可切换范围内月份；点击某日查看当天支出。 |
| 累计支出 | 以周期内已过日期对齐本期和比较期累计支出，显示明确的日期与金额；缺少比较数据时只显示本期。 |
| 分类走势 | 分类与月份的金额热力表，按所选范围展示月份；选择分类查看连续月份走势。年范围展示全年，截至当前日期；月范围可快捷切换该年。 |
| 金额分布 | 支出分为低于 50、50–199.99、200–499.99、500–999.99、1,000–4,999.99、5,000 元及以上；展示笔数/金额及中位数、最大支出、前五笔占比，点击区间进入对应记录。 |
| 月度复盘 | 月范围显示收支概况、最大分类变化、最大支出和大额集中程度等简短事实，提供相应明细链接。跨月范围不显示冒称单月的摘要。 |

#### 日期与比较

- 当前月、当前年和最近三个月的统计截止上海今日；未来日期不纳入已发生复盘。已结束月份、年份使用完整周期。
- 最近三个月指当月及前两个月，从首月 1 日至今天。自定义日期含首尾两天，必须是真实日期且开始不晚于结束，未来端点截到今天；空值或非法 URL 回到当前月，表单错误保留输入并提示。
- 完整月与前一完整月比较；进行中的月比较上月截至相同日，短月截至月末。年比较上年对应进度；最近三个月比较前一组三个月对应进度；自定义范围比较紧邻之前的等长日期。
- 同比将起止日期映射到上一年，闰日取该年二月末。全部范围没有自然基期，明确不显示增幅。
- 图表只把无记录日期填零用于表达已记录金额，文字明确其不是账目完整性证明；首条记录之前或整个基期无记录时提示数据不足。
- 不超过 366 天的选择保留完整日期和月份。更长范围的图形省略首条记录之前的空白历史；空账本只绘制结束月份，总额与所选主范围保持不变。

### 技术设计

共享范围模块解析 `mode/month/year/start/end`，其中自定义日期使用 `start/end`，现有 `from/to` 继续用于缩小明细窗口。导航和表单返回链接使用同一序列化方式。

`queryHomeReport` 保留现有总览查询。新增分析查询复用已解析范围，以数据库聚合返回两期概况、分类与日期汇总、分类月度矩阵、金额分桶和分位指标，不向浏览器传送完整历史交易。

图表服务端容器生成明细 URL；金额区间使用已有加密金额筛选，类别和日期使用现有筛选语义。交互组件接收序列化的聚合数据和链接，支持触摸、键盘及文字替代信息。新增文案统一进入 `src/lib/i18n.ts`。
