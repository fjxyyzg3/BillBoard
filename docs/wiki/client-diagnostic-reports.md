# 客户端诊断功能移除约定

“反馈卡顿”功能已整体移除，不再采集或上报浏览器诊断现场，也不提供报告查看或处理接口。桌面侧栏和移动端更多菜单保留原有导航、账号、语言切换、版本及 Android 更新能力；页面加载失败时继续提供双语提示和重试。

`ClientDiagnosticReport` 表、全部历史诊断报告及专用 `ClientDiagnosticReportStatus` 枚举通过新增迁移删除。既有迁移保留，以支持旧数据库升级和全新数据库按顺序重放。删除范围只包含诊断报告，家庭、成员、账本、账务、会话及业务 `AppEvent` 不受影响。

`DIAGNOSTIC_AGENT_TOKEN` 不再被应用或容器使用。恢复旧备份后，必须在开放服务前应用当前迁移，重新删除备份中的诊断表和报告，不恢复已移除的接口。

原功能的历史设计见 [客户端诊断现场上报 spec](../scope/2026-09-02-client-diagnostic-reports.md)，其中的入口、采集、30 天清理和 Agent API 约定已失效。
