> 摘要：Windows x64 客户端以 Electron 连接现有 HTTPS 家庭服务，在公开帮助页提供 NSIS 安装包，应用内更新保留会话认证与独立签名校验。

# Windows 家庭客户端

Windows 客户端面向家庭自用，复用现有 PC 页面、账号密码及服务端 AppSession；数据和业务处理仍由现有服务负责，不部署本机数据库或提供离线记账。首版交付 x64 安装包，以 Windows 11 x64 为主要验收环境。当前用户级安装保持产品标识、持久会话和资料目录稳定，覆盖升级保留已持久化的受保护材料，不延长会话或恢复失效身份。

Electron 远程页面使用沙箱、上下文隔离和受限同源权限。网页不能访问 Node.js、Cookie、任意原生路径或命令；外部 HTTPS 页面交给系统浏览器。家庭码与状态首先复用 IndexedDB／Web Crypto 保护，显式退出和身份结束按原规则清理。

`/help` 提供无需登录的中英文完整使用教程和 Android、Windows 下载入口，可从登录页、手机“更多”和桌面侧栏进入。`GET /api/downloads` 提供各平台最新发布版本和大小等下载信息，`GET /api/downloads/windows` 提供当前正式 x64 EXE；公开信息来自 Windows 发布清单，不使用网页版本代替安装包版本。未发布或不可用时明确显示状态，不影响教程或另一平台下载。首次安装使用系统浏览器下载；原生壳限制普通安装包下载，已安装客户端使用“客户端更新”。公开下载不授予账号或家庭权限，新增或更新网页帮助内容不需要重建 EXE。

应用内更新由检查、下载和明确安装组成。`GET /api/windows/update` 清单及 `GET /api/windows/update/<sha256>` 安装包仍经原会话认证的固定同源端点提供；客户端用内置 Ed25519 公钥验证原始清单 payload，再核对版本、平台、大小和 SHA-256。签名私钥只由维护者私下保管，服务不持有私钥；这不提供 Windows 受信发布者身份，首次安装可能出现相关系统提示。

安装前须保存未提交内容，收敛录音、记账、导入导出和家庭加密操作；未知状态禁止安装。下载完成、后台、关闭面板及普通退出不自动安装。NSIS 安装器等待原进程正常退出，不强杀正在运行的客户端；实际安装版本和重启后的状态用于核验升级结果。

正式安装包通过现有 HTTPS 服务公开分发，包含连接服务所需的地址；真实入口仍不得写入 Git 跟踪文件或历史。签名材料、本地配置、构建和发布产物均排除在 Git 与 web 镜像外，私钥和未发布产物不公开，也不新增第三方托管。正式产物从完整验证且已推送的干净 master 构建，本机发布先写不可变摘要文件，再原子切换签名清单。网页发布与桌面容器版本分开判断。
