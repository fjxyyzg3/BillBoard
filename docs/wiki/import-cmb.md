# 招商银行账单导入

BillBoard 在 `/records/import` 中以 `cmb` 来源接收招商银行官方借记卡交易流水。当前支持直接上传 `.pdf`，也支持招商银行提供的带密码 `.zip`；两种文件最终都进入同一套 PDF 版式解析、成员映射、分类映射、重复复核和批量确认流程。

## 上传与密码

招商银行 ZIP 上传时由用户在上传表单填写解压密码。密码只随当前 server action 请求传递，不写入 URL、事件 metadata、日志、草稿、交易或浏览器持久化存储。直接上传 PDF 时不需要密码。

服务端先校验来源、扩展名和 20MB 文件上限，再读取内容。ZIP 必须能用该密码解压出且仅出一个 PDF；缺少密码、密码错误、ZIP 损坏、entry 数量不符或内容不是 PDF 时不创建导入草稿。

## 解析与账本边界

ZIP 在服务端内存中解压，使用支持 ZipCrypto 的 ZIP reader，不调用系统命令、不落盘、不访问第三方服务。解压得到的 PDF 只在当前请求中交给现有 CMB PDF parser；导入草稿文件名固定为 `cmb.pdf`，不保存用户上传的原始文件名。

解析结果继续遵守招商银行导入约定：金额以整数分保存，日期按 `Asia/Shanghai`，分类映射按 `cmb|transactionType|交易摘要|对手信息` 聚合，成员归属从当前家庭 session 和已保存的 CMB 成员映射派生。账号和联机余额只参与内存中的来源指纹计算，备注只保留交易摘要和对手信息。

疑似转账、汇款、证券、理财、还款等资金移动默认跳过，但用户可以在复核阶段恢复；恢复后仍必须经过成员、分类和重复检查。

## 验证与扩展

测试使用脱敏 PDF 和运行时生成的测试密码 ZIP，不保存用户提供的真实账单、密码或 ZIP 文件。银行改变 PDF 版式时，解析器应先失败关闭；新增版式需要新的脱敏样本、parser 测试和安全审查后再扩展。
